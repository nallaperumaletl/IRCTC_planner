# IRCTC_planner

IRCTC Planner is a responsive train ticket booking-date calculator for the 60-day Advance Reservation Period (ARP). Select a travel date or booking date to instantly calculate the corresponding date, with support for holidays, leave days, saved options, and mobile-friendly calendar navigation.

## Features

- Calculate booking and travel dates using the 60-day ARP.
- Responsive calendar with swipe and button navigation.
- Gen60 planner for upcoming travel cycles, routes, office days, and return planning.
- Configure station routes, preferred weekdays, holidays, and leave days.
- Save date options and generate PDF travel plans.
- Add booking reminders to Google Calendar or download ICS calendar events.
